🔑 1. 접속 & 로그인

1
finance.villagebaby.kr 접속
2
회사 이메일 아이디 입력 (예: hong — @villagebaby.kr은 자동으로 붙어요) → 인증코드 받기
3
회사 메일로 온 인증코드를 입력하면 로그인 완료. 별도 가입이나 비밀번호는 없어요.
💡 인증코드 메일은 "빌베 연차" 이름의 [빌리지베이비] 사내 시스템 로그인 코드 제목으로 와요. 연차 사이트와 로그인 시스템을 같이 쓰고 있어서 그래요 — 재무 사이트 코드가 맞으니 그대로 입력하시면 됩니다.
💡 로그인이 안 되면 회사 이메일이 명단에 등록되어 있는지 재무팀(정채영님)에게 문의해주세요.

💸 2. 이체 요청하기

거래처 대금, 외주비 등 회사 계좌에서 이체가 필요한 모든 건은 여기서 신청합니다.

1
왼쪽 메뉴 이체 요청 → 오른쪽 위 + 새 이체 요청
2
거래처/예금주 입력 — 칸 오른쪽 ▾를 누르면 등록된 거래처 목록이 떠요. 선택하면 가장 최근에 사용한 은행·계좌번호가 자동 입력됩니다. 처음 거래하는 곳이면 이름을 그대로 입력하고 은행·계좌를 직접 적으면 돼요.
3
금액과 이체 희망일(실제 이체가 필요한 날) 입력 — 희망일을 고르면 증빙의 작성일자도 같은 날로 자동 설정돼요 (필요하면 직접 수정 가능)
4
분류 선택, 적요/메모에 무슨 건인지 적기 (예: "9월 광고비 정산")
5
증빙 유형 선택 (아래 표 참고) → 요청 등록

증빙 유형 고르는 법

유형언제 선택하나요?
세금계산서 (매입)거래처가 세금계산서를 발행해주는 일반적인 거래
현금영수증 (지출증빙)현금영수증(지출증빙용)을 받는 경우
계산서 (면세)면세 물품·용역 (계산서 수취)
신용카드 전표카드 전표로 증빙되는 경우
거래명세서·영수증위 증빙이 없는 경우 — Dropbox 링크 필수
증빙 없음급여·인건비, 해외송금, 공과금 등 — 사유 기재 필수
⚠️ 적격증빙을 못 받으면 가산세(2%)가 부과됩니다. 증빙 유형을 꼭 정확히 선택해주세요.

처음 거래하는 거래처라면?

폼에 "첫 거래처네요!" 안내가 뜹니다. 통장사본 + 사업자등록증(개인은 신분증 사본)을 Dropbox Finance 폴더에 올리고 링크를 기재해주세요. 이후 거래처 관리에 등록되면 다음부터는 자동 인식됩니다.

매달 반복되는 이체라면?

폼 아래 🔁 매월 정기 이체로 등록을 체크하고 반복 횟수를 입력하면, 매달 자동으로 다음 회차가 준비됩니다.

목록에서 내 요청 확인하기

이체 요청 목록의 위쪽 탭(전체 9월 2026년 기간지정)으로 기간을 고를 수 있어요. 월·연도 탭을 누르면 드롭다운으로 다른 달·다른 해도 선택됩니다. 월 기준은 이체희망일이에요 — 10월에 이체될 건은 10월 탭에 보여요.

✏️ 3. 내 요청 수정·삭제

  • 목록에서 내가 쓴 요청의 오른쪽에 ✏️(수정) · 🗑(삭제) 버튼이 보여요. (요청을 클릭해 상세 팝업에서도 가능)
  • 지급대기 상태에서만 수정·삭제할 수 있어요. 지급완료된 건은 변경 불가합니다.
  • 다른 사람의 요청은 수정·삭제할 수 없어요. (관리자 제외)

🚗 4. 유류비·출장비 신청

본인 계좌로 정산받는 이동 경비입니다. 왼쪽 메뉴 유류비 신청에서:

  • 일자, 차량번호, 출발지 → 도착지(왕복 여부), 방문 목적, 거리(km), 본인 입금 계좌 입력
  • 유류비는 네이버 지도 기준 금액 + 30%로 지급됩니다

🧾 5. 세금계산서 발행 요청

우리 회사가 거래처에게 세금계산서를 발행해줘야 할 때(매출) 신청합니다.

1
세금계산서 발행 메뉴 → + 새 발행 요청
2
상호 입력(등록 거래처면 사업자번호·이메일 자동), 대표자·이메일 확인
3
작성일자와 품목명, 공급가액 입력 — 세액·합계는 자동 계산
4
요청 등록 → 재무팀이 확인 후 발행하면 발행완료로 바뀝니다
⚠️ 세금계산서는 당월분 → 익월 10일까지만 발행할 수 있어요. 기한이 지나면 발행 불가(가산세 대상)이니 월말 건은 서둘러 요청해주세요.

발행 요청도 이체 요청과 같은 규칙으로 본인 건은 발행완료 전까지 수정·삭제할 수 있습니다.

📝 6. 지출결의 · 기명 법카 신고

  • 지출결의: 개인 비용으로 먼저 쓰고 정산받는 경비 — 사용일, 사용처, 금액, 용도, 증빙을 입력해 신청
  • 기명 법카 신고: 본인 명의 법인카드 사용 내역 신고 — 카드 뒷 4자리, 사용 내역 입력

📌 8. 꼭 지켜주세요

  • 세금계산서(매입) 작성일 = 실제 이체 당일로 맞춰주세요
  • 세금계산서(매입·매출)는 당월분 → 익월 10일까지만 발행 가능
  • 발행 전 공급가액·세액·합계금액을 한 번 더 확인
  • 발행 주체 = 실제 예금주가 같은지 확인 후 요청
  • 1천만원 이상 이체는 고액 건으로 기록되니 증빙을 더 꼼꼼히 챙겨주세요
